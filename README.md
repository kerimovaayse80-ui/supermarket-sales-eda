# Supermarket Sales EDA

Exploratory Data Analysis of supermarket sales data using Python.

## Project Overview

This project focuses on exploring supermarket transaction data and understanding sales patterns across different business dimensions.

The analysis was performed using Python and covers data preparation, exploratory analysis, aggregation, time-based analysis, and data visualization.

## Objectives

The main objectives of this project are to:

- Explore and understand the dataset
- Check data quality
- Prepare date and time data for analysis
- Analyze sales across branches and product lines
- Compare customer types and gender
- Identify sales patterns by hour and month
- Identify the highest- and lowest-performing product lines
- Create meaningful visualizations
- Perform additional analysis using gross margin and branch-product relationships
- Extract business insights from the analysis

## Dataset

The dataset contains **1,000 transactions and 17 columns** related to supermarket sales.

The dataset includes information such as:

- Branch
- Customer type
- Gender
- Product line
- Unit price
- Quantity
- Total sales
- Date
- Time
- Payment method
- Gross income
- Customer rating

Data quality was checked before performing the analysis.
